# CarShop UI

Angular-клієнт для [CarShop API](../CarShop).

## Запуск

1. Запустіть API (`CarShop.API`) на `https://localhost:5001`
2. У цій папці:

```bash
npm install
npm start
```

Відкрийте http://localhost:4200

Проксі (`proxy.conf.json`) перенаправляє `/api` та `/images` на бекенд.

## Можливості

- Каталог з фільтрами
- Деталі оголошення, дзвінок продавцю
- Реєстрація / вхід (JWT)
- Продаж авто + завантаження фото
- Мої оголошення, обране
